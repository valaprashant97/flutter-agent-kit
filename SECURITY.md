# Security Policy

## Supported Versions
The Flutter Agent Kit tracks the latest Flutter Stable channel releases.

| Version | Supported |
| :--- | :--- |
| **1.0.x** | :white_check_mark: |
| **< 1.0** | :x: |

---

## Reporting a Vulnerability

Security is a foundational tenet of the Flutter Agent Kit. If you discover a vulnerability or security risk (such as instructions that could inadvertently expose credentials, weaken platform sandboxing, or compromise local storage):

1. **Do not open a public issue.**
2. Send a detailed report to the security maintainers at: `security@flutteragentkit.dev`.
3. Include:
   - Affected file, skill, or workflow.
   - Attack vector or potential vulnerability description.
   - Remediation suggestion.
4. The maintainers will respond within 48 hours and coordinate a coordinated disclosure timeline.
